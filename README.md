# Электронная библиотека

## Структура БД

| Таблица | Поля |
| --- | --- |
| Книги | id, название, дата публикации, описание |
| Авторы | id, имя, фамилия |
| Жанры | id, название, описание |
| Пользователи | id, имя, электронная почта |
| Книги_Авторы | ID автора, ID книги |
| Книги_жанры | ID книги, ID жанра |
| Книги_пользователи | ID книги, ID пользователя, дата добавления, статус |

Связующие таблицы сопоставляют книги с авторами, жанрами и пользователями.

## Структура API

### Книги

| Метод | URL | Назначение и параметры | Ответ |
| --- | --- | --- | --- |
| GET | `/api/books` | Список; фильтры `search`, `genre_id`, `author_id` | 200 |
| GET | `/api/books/{id}` | Информация о книге | 200 / 404 |
| POST | `/api/books` | Создать книгу (админ) | 201 / 400 |
| PATCH | `/api/books/{id}` | Изменить поля книги (админ) | 200 / 404 |
| DELETE | `/api/books/{id}` | Удалить книгу (админ) | 204 / 404 |

### Авторы

| Метод | URL | Назначение и параметры | Ответ |
| --- | --- | --- | --- |
| GET | `/api/authors` | Список авторов | 200 |
| GET | `/api/authors/{id}` | Информация об авторе | 200 / 404 |
| POST | `/api/authors` | Добавить автора (админ) | 201 / 400 |
| PATCH | `/api/authors/{id}` | Изменить автора (админ) | 200 / 404 |
| DELETE | `/api/authors/{id}` | Удалить автора (админ) | 204 / 404 |

### Жанры

| Метод | URL | Назначение и параметры | Ответ |
| --- | --- | --- | --- |
| GET | `/api/genres` | Список жанров | 200 |
| POST | `/api/genres` | Создать жанр (админ) | 201 / 400 |
| PATCH | `/api/genres/{id}` | Переименовать жанр (админ) | 200 / 404 |
| DELETE | `/api/genres/{id}` | Удалить жанр (админ) | 204 / 404 |

### Авторизация и профиль

| Метод | URL | Назначение и параметры | Ответ |
| --- | --- | --- | --- |
| POST | `/api/auth/register` | Регистрация пользователя | 201 / 400 / 409 |
| POST | `/api/auth/login` | Вход в систему | 200 / 401 |
| GET | `/api/users/me` | Профиль текущего пользователя | 200 / 401 |

### Личная библиотека

| Метод | URL | Назначение и параметры | Ответ |
| --- | --- | --- | --- |
| GET | `/api/users/me/books` | Своя коллекция; фильтр `status` | 200 / 401 |
| POST | `/api/users/me/books` | Добавить книгу в коллекцию | 201 / 404 / 409 |
| PATCH | `/api/users/me/books/{book_id}` | Изменить статус или оценку | 200 / 404 |
| DELETE | `/api/users/me/books/{book_id}` | Убрать книгу из коллекции | 204 / 404 |
